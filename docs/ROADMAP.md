# Roadmap

## المرحلة 1: إعداد الأساس والبنية التحتية
**الهدف:** تجهيز المشروع للبدء

**ما تحتويه:**
- [ ] تهيئة مشروع Astro
- [ ] إعداد i18n (عربي/إنجليزي)
- [ ] إعداد هيكل المجلدات
- [ ] إعداد linting وformatting
- [ ] إعداد GitHub Actions CI

**شرط النجاح (اختبارات محددة تنجح):**
- [ ] 
pm run build ينجح بدون أخطاء
- [ ] 
pm run lint ينجح
- [ ] CI يعمل على PR ويشغل البناء والاختبار
- [ ] يمكن التبديل بين اللغتين

**ما خارجها:**
- تصميم مفصّل
- إضافة جميع الأعمال
- تحسينات SEO متقدمة

## المرحلة 2: المحتوى والصفحة الرئيسية
**الهدف:** عرض المعلومات الأساسية

**ما تحتويه:**
- [ ] قسم Hero (الاسم، المهنة، الموقع)
- [ ] قسم الإحصائيات (خبرة، عملاء، مشاريع)
- [ ] قسم البرامج المستخدمة
- [ ] قسم المهارات
- [ ] معلومات التواصل

**شرط النجاح:**
- [ ] جميع المعلومات من PRD تظهر بشكل صحيح
- [ ] التصميم متجاوب على الموبايل
- [ ] يدعم اللغتين
- [ ] اختبار يدوي: عرض صحيح على 3 أحجام شاشة على الأقل

**ما خارجها:**
- معرض الأعمال الكامل
- أنيميشن معقد

## المرحلة 3: معرض الأعمال
**الهدف:** عرض جميع أعمال أحمد

**ما تحتويه:**
- [ ] تصنيف الأعمال (Shorts, Real Estate, Music Clips, Documentary/Story)
- [ ] عرض روابط يوتيوب
- [ ] تصفية حسب النوع
- [ ] معاينة مختصرة

**شرط النجاح:**
- [ ] جميع الروابط الـ17+ تظهر
- [ ] التصنيف صحيح
- [ ] الروابط تعمل وتفتح بشكل صحيح
- [ ] متجاوب

**ما خارجها:**
- تشغيل الفيديو داخل الموقع
- نظام تعليقات

## المرحلة 4: التحسينات والاختبار النهائي
**الهدف:** جاهزية للإطلاق

**ما تحتويه:**
- [ ] تحسين SEO أساسي
- [ ] تحسين الأداء
- [ ] اختبار شامل
- [ ] مراجعة الأمان
- [ ] إعداد للنشر

**شرط النجاح:**
- [ ] جميع الاختبارات تنجح على كل الأنظمة
- [ ] Lighthouse score >= 90
- [ ] لا توجد مفاتيح أو بيانات حساسة
- [ ] مراجعة نهائية

**ما خارجها:**
- ميزات إضافية
- نظام إدارة محتوى
