# Architecture Document

## نظرة عامة
My Portfolio هو تطبيق ويب متجاوب (مع إمكانية تحويله لتطبيق أندرويد لاحقًا). يركز على عرض محتوى ثابت مع دعم ثنائي اللغة.

## أجزاء المشروع
1. **الواجهة الأمامية (Frontend)**
   - عرض المعلومات الشخصية والإحصائيات
   - معرض الأعمال مصنّف حسب النوع (Shorts, Real Estate, Music Clips, Documentary/Story)
   - مبدّل اللغة (عربي/إنجليزي)
   - قسم التواصل

2. **المحتوى (Content)**
   - بيانات ثابتة (معلومات شخصية، إحصائيات، برامج، مهارات)
   - روابط يوتيوب للأعمال (منشورة فقط)

3. **البنية التحتية (Infrastructure)**
   - استضافة ثابتة (Static Hosting)
   - CI/CD عبر GitHub Actions
   - نظام إصدارات تلقائي من GitHub

## كيف يتصل بعضها ببعض
`
[المستخدم] --> [متصفح الويب] --> [ملفات ثابتة HTML/CSS/JS] --> [روابط يوتيوب الخارجية]
`

- جميع المحتويات ثابتة، لا توجد استدعاءات API في المرحلة الأولى
- الروابط تفتح في تبويب جديد أو مدمجة حسب التصميم
- التبديل اللغوي يتم عبر JavaScript محلياً
- لا يوجد اتصال بقاعدة بيانات

## اعتبارات التصميم
- **الأداء**: ملفات ثابتة، تحميل سريع
- **التجاوب**: يعمل على الموبايل والتابلت والكمبيوتر
- **إمكانية الوصول**: استخدام HTML دلالي
- **قابلية التوسع**: يمكن إضافة CMS لاحقاً دون إعادة هيكلة كبيرة
- **الأمان**: لا مفاتيح أو بيانات حساسة، تنظيف المدخلات إن وجدت

## التقنيات المقترحة
سيتم تحديدها في ADRs، لكن البنية تدعم:
- HTML/CSS/JavaScript خالص أو إطار عمل حديث
- إمكانية تحويل لPWA أو تطبيق أندرويد لاحقاً
