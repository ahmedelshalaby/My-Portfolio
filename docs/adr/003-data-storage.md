# ADR-003: طريقة حفظ البيانات

## الحالة
مقترح - ينتظر الموافقة

## السياق
يجب عرض معلومات ثابتة وروابط يوتيوب. لا حاجة لقاعدة بيانات معقدة في المرحلة الأولى.

## الخيارات
1. **ملفات JSON ثابتة** (data.json)
2. **ملفات Markdown**
3. **TypeScript/JavaScript Objects**
4. **Frontmatter في Astro**

## القرار المقترح
الخيار 4: Frontmatter في Astro مع ملفات .md أو ملفات data في src/data/

## السبب
- متكامل مع Astro
- سهل التعديل
- نوع آمن مع TypeScript
- مناسب للمحتوى الثابت
- لا يحتاج لقاعدة بيانات

## العواقب
- إيجابية: بسيط، آمن، سريع
- سلبية: يحتاج لإعادة البناء عند التعديل (لكن عبر CI تلقائياً)
