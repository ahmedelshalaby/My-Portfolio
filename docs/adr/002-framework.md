# ADR-002: اختيار الإطار التقني

## الحالة
مقترح - ينتظر الموافقة

## السياق
يجب أن يعمل المشروع على موقع ويب وأندرويد. يحتاج لأداء سريع وتصميم متجاوب.

## الخيارات
1. **HTML/CSS/JavaScript خالص (Vanilla)**
2. **Vue.js 3 + Vite**
3. **React + Vite**
4. **Astro (Static Site Generator)**

## القرار المقترح
الخيار 4: Astro

## السبب
- مثالي للمواقع الثابتة (Static Site)
- أداء ممتاز جداً (Zero JS افتراضياً)
- سهولة التحويل لـPWA
- يدعم i18n بسهولة
- بناء سريع
- مثالي لعرض محتوى ثابت كبورتفوليو
- يمكن تحويله لتطبيق أندرويد لاحقاً عبر Capacitor إذا لزم الأمر

## العواقب
- إيجابية: أداء عالي، بسيط، مناسب للغرض
- سلبية: يحتاج لتعلم Astro إذا لم يكن معروفاً، لكن مناسب جداً لهذا المشروع
