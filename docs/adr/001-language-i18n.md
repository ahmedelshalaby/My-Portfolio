# ADR-001: اختيار اللغة ودعم ثنائي اللغة

## الحالة
مقترح - ينتظر الموافقة

## السياق
المشروع مطلوب بالغة العربية أولاً، مع إمكانية التبديل للإنجليزية بضغطة زر.

## الخيارات
1. **ملفات ترجمة JSON منفصلة** (ar.json, en.json) مع نظام i18n
2. **بيانات مدمجة في JS/TS** مع كائنات الترجمة
3. **صفحات منفصلة** (index-ar.html, index-en.html)
4. **نظام ترجمة بسيط بالـdata attributes**

## القرار المقترح
الخيار 1: ملفات ترجمة JSON منفصلة

## السبب
- سهولة الصيانة والإضافة
- فصل المحتوى عن المنطق
- قابلية التوسع لإضافة لغات أخرى مستقبلاً
- معيار شائع
- لا يحتاج لبناء معقد

## العواقب
- إيجابية: تنظيم أفضل، سهل التعديل
- سلبية: يحتاج لfetch أو تضمين JSON
